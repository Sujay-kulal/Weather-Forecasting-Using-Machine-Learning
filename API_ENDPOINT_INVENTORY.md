# REST API Endpoint Inventory & Introspection Audit

**Project:** Weather Forecasting Using Machine Learning  
**Target Backend:** FastAPI + Uvicorn (Render deployment)  
**Verification Method:** FastAPI route reflection via `app.openapi()` and ASGI routing table traversal  
**Branch:** `audit/final-evidence-documentation`  
**Status:** VERIFIED (16 business endpoints + 4 framework routes)

---

## 1. Executive Summary

This inventory provides the definitive, code-verified audit of all HTTP endpoints exposed by the backend application (`backend/app/main.py`).

Historical documentation in earlier audit passes intermittently cited "18 endpoints" due to either counting OpenAPI documentation helpers or speculating on unmerged administrative routes. Live ASGI reflection confirms that the application registers exactly:
- **16 Business Endpoints** across 16 route paths implementing the core forecasting, weather history, location hierarchy, ML telemetry, and administrative operations.
- **4 Framework Documentation Endpoints** auto-generated by FastAPI (`/openapi.json`, `/docs`, `/redoc`, `/docs/oauth2-redirect`).

Every endpoint was checked for path definition, HTTP method, required query/path parameters, payload contracts, response models, authentication safeguards, and corresponding automated test coverage.

## 4. Discrepancy Reconciliation (16 vs 18 Endpoints)

In previous documentation iterations, the API endpoint count was variously reported as 18 or 16. The discrepancy is reconciled as follows:

1. **Root cause of the "18" claim:** Early planning documents counted 16 business endpoints and added 2 documentation endpoints (`/docs` and `/redoc`), totaling 18, while omitting `/openapi.json` and `/docs/oauth2-redirect`. Alternatively, some drafts assumed separate CRUD mutation endpoints for locations (`POST /locations`, `DELETE /locations`) which do not exist in the code.
2. **Current Verified Reality:** 
   - Exactly **16 operational business endpoints**.
   - Exactly **4 framework utility routes**.
   - Total HTTP routes registered in FastAPI ASGI application: **20 routes**.

## 5. Security & Authentication Audit per Endpoint

- **Public Endpoints (15/16):** All query and forecast endpoints are read-only (or ephemeral ML inference writes) designed for consumption by the React frontend without user authentication.
- **Protected Endpoint (1/16 - `/admin/ingest`):**
  - Protected via header `X-Admin-Token`.
  - Backed by environment variable `ADMIN_TOKEN`.
  - Verified protection: Unset `ADMIN_TOKEN` returns HTTP 401 Unauthorized; mismatched token returns HTTP 401 Unauthorized; missing header returns HTTP 401 Unauthorized.
  - Constant-time comparison using `secrets.compare_digest` prevents timing side-channel attacks.
  - Parameter bounds validation enforces `1 <= days_back <= 90`. Non-integer or out-of-bounds inputs return HTTP 422 Unprocessable Entity.
- **SQL Injection Safeguards:** All 16 endpoints use SQLAlchemy ORM or Core parameterized queries (`text("...").bindparams(...)`). Zero string interpolation of user input exists in SQL execution paths.
